# Mini Fantasy League Manager
A Java console application developed as a college project.

## Overview

Fantasy League Manager allows users to create teams, add players,
simulate matches, view player/team statistics, and export league
information to a text file.

## Features

- Create teams
- Add players with positions and skill levels
- Simulate matches between teams
- Select an MVP based on player skill
- Track player statistics
- View team rosters and statistics
- Export league data to a text file

## Concepts Practiced

- Object-Oriented Programming
- Java classes and objects
- ArrayLists
- Loops and conditional statements
- User input with Scanner
- File I/O
- Exception handling
- Random number generation

## Technologies

- Java
